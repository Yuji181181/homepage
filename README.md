## URL

https://yuji181181.pages.dev

## Tech Stack

| カテゴリ | 技術 |
|---------|------|
| フレームワーク | Vite + React |
| スタイリング | TailwindCSS + shadcn/ui |
| テスト | Vitest (統合テスト) |
| Lint/Format | OxC |
| ランタイム | Bun |
| デプロイ | Cloudflare Pages |

## セクション

- **Hero** - プロフィール画像、肩書き、SNSリンク
- **インターン** - 6社のインターン経験（タイムライン形式）
- **活動経歴** - 資格、セミナー、合宿（タイムライン形式）
- **制作物** - 3つのプロジェクト紹介
- **技術記事** - Qiita/Zennの記事一覧（静的データ）

## ローカル開発

```bash
# 依存関係のインストール
bun install

# 開発サーバー起動
bun run dev

# ビルド
bun run build

# テスト
bun run test

# Lint
bun run lint
```
